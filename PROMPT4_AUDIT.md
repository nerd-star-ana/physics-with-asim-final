# Prompt 4 UX Audit

## Executive summary
The project already has a workable app-router foundation and a solid route skeleton, but the page-level visual system is still too repetitive. The main issue is not missing architecture; it is missing differentiated identity. Pages share the same neutral card rhythm, same glass treatment, same spacing logic, and the same blue-first tone. The result is a premium route skeleton with a generic visual language.

## Current page-by-page audit

### Home
Weaknesses:
- Cinematic concept exists, but the hero still relies on a flat card-and-gradient composition.
- Motion is limited to soft section reveals and does not feel like a true physics-driven hero experience.
- Background is still generic compared with the premium brief.
- Color language remains blue-first and slightly safe rather than expressive.

### About
Weaknesses:
- Storytelling is present, but the page remains too close to a simple info layout.
- The layout lacks a strong narrative progression or milestone rhythm.
- Visual identity is not distinct from the rest of the site.

### Teaching Levels
Weaknesses:
- Page is structured, but still behaves like a card list instead of a premium qualification dashboard.
- No clear comparison or roadmap-style hierarchy.
- The content is informational rather than immersive.

### Courses
Weaknesses:
- The route is a standard listing page with no strong magazine or editorial feel.
- Card styling is too uniform.
- No visual distinction between course families or difficulty bands.

### Resources
Weaknesses:
- Resource directory exists, but the page lacks strong library identity.
- It feels like a static list rather than a curated digital library.
- Search is present, but visual browsing is weak.

### Results
Weaknesses:
- The page is too minimal and reads as a placeholder KPI block.
- There is no rich charting or visual story arc.
- Progress is described, but not dramatized.

### Testimonials
Weaknesses:
- Page is too card-only and lacks editorial layout depth.
- No testimonial wall, carousel, or student intimacy.
- Reviews do not create a premium social proof experience.

### FAQ
Weaknesses:
- FAQ is simple and static.
- The interaction lacks layered visual identity or a category-story feel.
- It remains visually too close to a generic support page.

### Contact
Weaknesses:
- A split layout exists, but it still feels like a standard business contact form.
- No stronger business identity, location story, or premium brand presence.
- The page lacks its own distinctive mood.

## Cross-page pattern issues
- Repeated glass-card presentation across many pages.
- Repeated neutral background treatment with minimal section contrast.
- Repeated layout rhythm using one generic card stack.
- Shared typography hierarchy is present, but not premium enough.
- Dark mode is functional only at a basic level and lacks a fully designed system.
- Motion is mostly decorative; it does not define page identity.

## Planned fixes
1. Give each route its own background composition, layout rhythm, and motion behavior.
2. Introduce a broader color system with unique section accents rather than a single blue palette.
3. Upgrade the theme system so dark mode feels intentional and persistent.
4. Replace generic repeated cards with unique editorial, dashboard, library, story, and social-proof patterns.
5. Add motion where it communicates hierarchy, not just decoration.
